# Архитектура Aura Beauty

## Общая схема

Aura Beauty — статический сайт из двух страниц. Для его просмотра не нужна база данных или серверная логика. Все тексты, ссылки и карточки сейчас находятся непосредственно в файлах страниц.

Главная страница → каталог → раздел категории → возврат на главную.

## Страницы

### Главная — `dist/index.html`

Содержит:

- шапку с логотипом и навигацией;
- крупный главный блок с фотографией;
- четыре категории товаров;
- блок «Почему Aura Beauty»;
- подвал.

Главная направляет посетителя в каталог целиком или сразу к выбранной категории.

### Каталог — `dist/products.html`

Содержит:

- ссылку возврата на главную;
- заголовок и кнопку «Каталог Aura Beauty»;
- быстрые ссылки на категории;
- разделы ухода за кожей и макияжа;
- карточки товаров;
- нижнюю кнопку возврата на главную.

Разделы имеют собственные адресные метки: `skincare` и `makeup`. Благодаря им ссылка может открыть сразу нужную часть каталога.

## Оформление — `dist/styles.css`

Один файл оформления используется обеими страницами. В нём находятся:

- цвета и шрифты;
- размеры и расположение блоков;
- оформление логотипа, кнопок и карточек;
- правила для компьютеров, планшетов и телефонов;
- мягкие эффекты наведения;
- поддержка системной настройки уменьшенной анимации.

## Изображения — `dist/assets/`

В этой папке находятся:

- главное изображение сайта;
- фотографии товаров;
- изображения, предоставленные владельцем проекта;
- временные иллюстративные фотографии для незаполненных позиций.

Названия файлов должны быть понятными и описывать товар. При замене фотографии ссылка на файл в карточке каталога также должна быть обновлена.

## Публикация

Настройки публикации хранятся в `.openai/hosting.json`. Для публикации используется содержимое папки `dist`. Сайт связан с проектом Aura Beauty в Sites и сейчас доступен только владельцу согласно существующим настройкам доступа.

## Текущие ограничения

- Нет корзины и оформления заказа.
- Нет оплаты.
- Нет поиска и сложных фильтров.
- Нет базы данных товаров.
- Названия, описания и цены пока заполнены не полностью.
- Изменение ассортимента выполняется вручную.

## Возможное развитие

Когда ассортимент будет утверждён, следующим разумным этапом станет отдельный структурированный список товаров. После этого можно добавить поиск, простые фильтры, карточку отдельного товара и только затем — корзину и оформление заказа.
