# Домашняя работа — урок 25

**Проект:** Aura Beauty
**Маршрут:** Б — страница магазина в браузере

## Цель

Проверить один пользовательский путь на опубликованном учебном сайте: открыть
каталог, начать с пустой корзины, добавить один товар и убедиться, что в корзине
появился тот же товар в количестве 1. Остановиться до оформления заказа.

## Почему понадобился инструмент

По файлам проекта можно увидеть код каталога и корзины, но это не подтверждает,
что опубликованная версия действительно работает в браузере. Поэтому потребовалось
обращение к живому учебному сайту.

Использован встроенный **Computer Use MCP** в Codex с браузерным управлением через
**Playwright API**. Это не отдельно установленный сервер `@playwright/mcp`.

## Что было выполнено

1. Открыт [учебный каталог Aura Beauty](https://aurabeauty-bice.vercel.app/products.html).
2. Подтверждено начальное состояние: корзина показывала 0 товаров.
3. В каталоге найден товар **The Ordinary — Niacinamide 10% + Zinc 1%**.
4. Кнопка «В корзину» нажата один раз.
5. Корзина открыта.

## Результат и подтверждение

В корзине отображался товар **Niacinamide 10% + Zinc 1%**, бренд **The Ordinary**,
количество **1**. В проверявшейся валюте была показана ориентировочная цена
**≈ 502 ₽**. Итоговый адрес остался:
[https://aurabeauty-bice.vercel.app/products.html](https://aurabeauty-bice.vercel.app/products.html).

Безопасный снимок корзины сделан во время проверки. На нём нет ключей, паролей,
контактных или платёжных данных.

Форма оформления стала видна, но поля не заполнялись. Заказ не создавался, оплата
не выполнялась, сообщения третьим лицам не отправлялись.

## Внешняя запись

Задача в GitHub или другом сервисе не создавалась: выбранный сценарий прошёл без
ошибки, а для сдачи достаточно чтения и проверки в браузере.

## Вывод

MCP позволил проверить фактическое поведение опубликованного магазина, которое
нельзя доказать только чтением исходного кода. Осталось при необходимости вручную
открыть учебную ссылку и сверить товар и количество по сделанному снимку.
