# База знаний AI-консультанта Aura Beauty

## Где находятся знания

Подтверждённые постоянные правила магазина хранятся в
`knowledge/aura_beauty.json`. В этом файле находятся условия доставки, оплаты,
просмотра заказов и уведомлений.

Названия товаров, актуальные цены, доступность и числовые остатки в JSON не
копируются. Во время каждого вопроса модуль `server/knowledge.py` получает их из
общего серверного каталога `products`, который уже используется ботом, Mini App и
проверкой заказа.

Поиск выполняется на сервере. В модель передаются только несколько найденных
публичных фрагментов. Покупатели, контакты, адреса и заказы в поиск не входят.

## Как обновлять

1. Менять постоянное правило только после подтверждения владельцем магазина.
2. Добавить или обновить отдельную запись в `knowledge/aura_beauty.json`.
3. Указать понятные ключевые слова, которыми покупатель может задать вопрос.
4. Запустить `python3 -m unittest discover -s tests -v`.
5. Проверить неизвестный вопрос: бот не должен придумывать ответ.

Цены и остатки обновляются только в общей таблице товаров, а не в базе знаний.

## Подключение AI

Серверный модуль `server/ai.py` подготовлен для OpenAI Responses API и модели
`gpt-6-luna`. Ключ читается только из серверной переменной:

`OPENAI_API_KEY`

Без этой переменной внешний AI API не вызывается. Бот честно сообщает, что AI
ещё не подключён, и показывает найденную подтверждённую информацию. Не добавляйте
реальное значение ключа в `.env.example`, Git, браузер или Mini App.

После добавления ключа запрос использует `store: false`, ограниченный контекст и
короткий шестисекундный тайм-аут. Ошибка модели не ломает меню или оформление.
